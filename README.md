# 躲避蛇（即时制文字小游戏）

纯静态网页版《躲避蛇》：即时制、撞断蛇身、三档难度（15×15 / 20×20 / 30×30）。

## 在线试玩

https://ydgj2575.github.io/crazysnack/

## 玩法

- 电脑：WASD / 方向键按住移动；手机：方向键移动（网页版）
- 撞蛇的「身体」把它撞断：被撞的那一节不会消失，会变成一条独立的蛇
- 被蛇头碰到扣 1 点生命（共 5 点），被撞后 1 秒无敌
- 场上所有蛇都变成只剩一个蛇头（长度 1）时胜利
- 开始游戏时选择难度

## 文件

- `index.html` / `style.css` / `js/`：游戏本体
- `需求说明.md`：完整需求与实现说明
- `screenshots/`：游戏截图

## 本地运行

直接用浏览器打开 `index.html` 即可；或 `npx serve` 起本地静态服务。
